# VitaePro

Premium AI-powered CV and Cover Letter Builder.

## Phase 1 status

Frontend foundation only:

- Next.js App Router + TypeScript + Tailwind CSS v4
- Design tokens matched to `design/` HTML
- App shell (sidebar, header, mobile nav)
- Reusable UI primitives (shadcn-style) + shared components
- Mock data (no backend)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — redirects to `/dashboard`.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — run production server
- `npm run lint` — ESLint

## Stack

Next.js · React · TypeScript · Tailwind CSS · shadcn/ui · Framer Motion · React Hook Form · Zod · Lucide React
